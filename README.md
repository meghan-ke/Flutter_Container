# Word of the Day Flutter App

A simple Flutter app that displays a different day and word of the day using a Container widget and interactive buttons.

## How to Run

1. Make sure Flutter is installed and configured.
2. Open the project folder in VS Code.
3. Run `flutter pub get`.
4. Run `flutter run`.
5. Select an Android emulator or connected Android device.

## Widget Description

The main UI uses a Container widget to display the current day and its corresponding word in a styled card.

## Three Container Attributes

* Width: Sets the width of the container to 280 pixels.
* Padding: Adds 25 pixels of space between the container's border and its contents.
* Decoration: Styles the container with a background color and rounded corners.

## Functionality

The Next Day button moves to the next day and displays its corresponding word.

The Reset Day button returns the display to Monday and its corresponding word.

The app uses setState() to update the UI when the value of number changes.
